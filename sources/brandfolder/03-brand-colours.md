# Brand colours

### Print vs. Digital Colour Codes

Please take note of the difference between print and digital applications to ensure you are using the correct colour codes listed on the following pages.

Print applications include materials such as brochures, posters, business cards, printed billboards, letterhead, books, magazines, pull up banners and more. Printed materials also include printing on non-paper materials such as vinyl or textiles. CMYK colours are most often used for print and Pantone colours are used for special print jobs.

Digital applications include anything that is primarily viewed/accessed on a screen, such as a computer, 
mobile device, tablet, TV, digital billboard, and more. Digital applications use RGB or HEX colours. 

Please follow the text and font sizes noted for each colour. These guides help create web accessibility (or text that is easier to read) for those who are visually impaired by meeting the contrast requirements for each colour.

## Primary colours

### Primary colours

Below are the primary colours for VCH’s visual identity. To keep VCH's brand cohesive, use these colours first for all purposes.
- **Ocean Blue** HEX #0078AE | RGB 0,120,174 | CMYK 100,16,0,27 | Pantone C 307 / U 307
- **Cloud White** HEX #FFFFFF | RGB 255,255,255 | CMYK 0,0,0,0 | Pantone C  / U 

## Secondary colours

### Secondary colours

Our secondary colour palette can be used when a range outside of the two primary colours is required. For example, for a series of web banners or VCH icons.

Accessibility rules when using these colour for digital text:

- Harbour Teal, Seaside Teal and Rainforest Green: Only use as text on white background. When using these colours as backgrounds, use white text in any font size, as long as it's easy to read.

- Cyan Blue: Only use this colour as text on dark backgrounds. When using this colour as backgrounds, use black text in any font size, as long as it's easy to read.
- **Harbour Teal** HEX #006271 | RGB 0,98,113 | CMYK 100,45,45,20 | Pantone C 3155 / U 3155
- **Seaside Teal** HEX #009793 | RGB 0,151,147 | CMYK 87,20,48,0 | Pantone C 7716 / U 7716
- **Rainforest Green** HEX #009E4E | RGB 0,158,78 | CMYK 96,8,100,0 | Pantone C 7482 / U 7482
- **Cyan Blue** HEX #D4EFFC | RGB 212,239,252 | CMYK 15,0,0,0 | Pantone C  / U 

## Accent colours

### Accent colours

You may use the colours below as accents when contrast to primary or secondary colours is needed. Accent colours are intended for smaller design elements, not for large blocks of colours.

Accessibility rules when using these colour for digital text:

- Sunset Green: You may use this colour text on black backgrounds, or black text on this colour in any font size, as long as it's easy to read.

- Sea Star Purple and Cool Grey: You may use this colour text on white backgrounds, or white text on this colour background in any font size, as long as it's easy to read.
- Sunshine Yellow: Do not use this colour as text. Only use black text on this colour as a background.
- Sunset Orage: Only use this colour as text if text is large and easy to read. Due to web accessibility requirements, we do not recommend this colour for digital applications. Sunset Orange is intended for print applications only.
- **Sunlit Green** HEX #C1D82F | RGB 193,216,47 | CMYK 29,0,100,0 | Pantone C 382 / U 382
- **Sea Star Purple** HEX #843275 | RGB 132,50,117 | CMYK 55,95,25,5 | Pantone C 512 / U 512
- **Emergency Red** HEX #FF1236 | RGB 255,18,54 | CMYK 0,93,79,0 | Pantone C 185C / U 185U
- **Cool Grey** HEX #53585F | RGB 83,88,95 | CMYK 63,52,44,33 | Pantone C Cool Gray 11  / U Cool Gray 11 
- **Sunshine Yellow** HEX #FFE850 | RGB 255,232,80 | CMYK 0,5,80,0 | Pantone C 113 / U 113
