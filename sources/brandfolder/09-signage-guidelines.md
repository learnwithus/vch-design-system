# Signage guidelines


## Colour use for facility type

### Colour use for facility type

VCH has adopted a colour-based strategy for exterior signage to help the public easily identify services. Colour will serve as the key differentiator across all property types. Assigning a core colour to each facility type will distinguish the services offered while reinforcing the overall VCH brand through consistent application of a unified system.
VCH primary brand, Hospitals, Rural Health Care Centres, Health Units and MHSU services should primarily use VCH's Ocean Blue and Cloud White.
- **Ocean Blue** HEX #0078AE | RGB 0,120,174 | CMYK 100,16,0,27 | Pantone C 307 / U 307
- **Cloud White** HEX #FFFFFF | RGB 255,255,255 | CMYK 0,0,0,0 | Pantone C  / U 
VCH Urgent and Primary Care Centres should primarily use VCH's Sea Star Purple.
- **Sea Star Purple** HEX #843275 | RGB 132,50,117 | CMYK 55,95,25,5 | Pantone C 512 / U 512
VCH Community Health Centres should primarily use VCH's Rainforest Green.
- **Rainforest Green** HEX #009E4E | RGB 0,158,78 | CMYK 96,8,100,0 | Pantone C 7482 / U 7482
VCH Family Health Clinic should primarily use VCH's Harbour Teal.
- **Harbour Teal** HEX #006271 | RGB 0,98,113 | CMYK 100,45,45,20 | Pantone C 3155 / U 3155
Multiple facilities colour use

When appearing with another VCH facility, the signage colour should default to the VCH main brand colours, ocean blue and white.

## Logo relationship

### Logo relationship

The signage logo relationship is based on VCH's brand standards. Some alternative arrangements and positioning are shown here to ensure flexibility with sign size.

- When paired with the full colour VCH logo on white, the text for the name of the facility should be in ocean blue. 

- Horizontal logos lock-ups will use the same baseline as the VCH logo. The leading is consistent with the primary version of the logo.

- The clinic name always goes before the facility type and is treated at the same size and weight as the facility type.
Use of identifying colour in signage

To help establish the facility’s identifying colour, when possible use the facility colour as the sign background with a white version of the VCH logo. Alternatively, the VCH full-colour logo may be used on a white background, with the facility name shown in white on the facility-colour background, as seen below.
