### Wave pattern

Our VCH pattern is inspired by our region's winding coastlines and varied topography. This pattern can be applied to the edges of layouts or solid shapes when the appropriate colour, clear space, sizing and placement is applied.

The VCH pattern is not required to be in all VCH branded layouts. The pattern is intended to be used as a design element to enhance the brand but only when spacing permits and the design layout benefits from its use.

The pattern has been applied to VCH templates such as letterhead, PowerPoints and posters. Contact brand@vch.ca if you would like to use the pattern beyond what is provided in the templates and require the pattern file.

Graphic designers should follow the guidelines below for pattern usage. 
- Do not change the colour of the wave pattern. The VCH pattern files are pre-tinted to 80%so they are lighter and visible on top of a background colour untinted at 100%.

-Use appropriate clear space for the pattern.
- Do not place text over the pattern because this decreases the legibility of the text
- If the pattern is contained within a shape, be sure there is enough clear space between the shape and the content to ensure it does not crowd or visually distract from the content.

- Do not place images over the pattern.

Pattern Application – Colour

The pattern is already applied to the VCH templates. Graphic designers should follow this guide to learn how to apply the correct background colours to their projects.

Only use the VCH pattern with the following background colours:
- **Ocean Blue** HEX #0078AE | RGB 0,120,174 | CMYK 100,16,0,27 | Pantone C 307 / U 307
