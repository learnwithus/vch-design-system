| [`logos/official/`](logos/official/) | `VCH_logo_master_2019.eps` (vector master) plus 1462px PNGs: full colour, reversed white, black | **Print, slides, documents, anything hi-res.** These are the masters. |

| [`screenshots/`](screenshots/) | Live vch.ca captures (2026-11-19) | Visual reference only |
